01. Mengenal Website Pribadi

Website pribadi adalah halaman internet yang dibuat untuk menampilkan identitas, karya, informasi, atau bahan pembelajaran seseorang.

Guru dapat menggunakan website pribadi sebagai media berbagi materi, modul, presentasi, video pembelajaran, dan aplikasi pendidikan.

02. Mengenal GitHub

GitHub adalah platform untuk menyimpan dan mengelola file kode secara online.

GitHub Pages memungkinkan kita menerbitkan website langsung dari repository GitHub.

Hal penting: Website yang diterbitkan dapat dibuka melalui link dan dibagikan kepada guru maupun siswa.

03. Membuat Akun GitHub

Langkah-langkah membuat akun:

  1. Buka GitHub Sign Up.
  2. Masukkan alamat email.
  3. Buat password yang kuat.
  4. Pilih username yang singkat dan profesional.
  5. Selesaikan verifikasi akun.
  6. Ikuti petunjuk sampai akun berhasil dibuat.
Username akan menjadi bagian dari alamat website. Pilih nama dengan teliti.

04. Membuat Repository

  1. Login ke GitHub.
  2. Klik tanda tambah (+) di kanan atas.
  3. Pilih New repository.
  4. Beri nama repository dengan format username.github.io.
  5. Pilih Public.
  6. Centang Add a README file.
  7. Klik Create repository.

Contoh: jika username GitHub adalah gurumaju, nama repository dapat dibuat menjadi gurumaju.github.io.

05. Membuat Halaman HTML

  1. Buka repository yang sudah dibuat.
  2. Klik Add file.
  3. Pilih Create new file.
  4. Beri nama file index.html.
  5. Masukkan kode HTML halaman utama.
  6. Klik Commit changes.

File index.html merupakan halaman utama website.

06. Mengaktifkan GitHub Pages

  1. Buka menu Settings.
  2. Pilih Pages.
  3. Pada bagian Build and deployment, pilih Deploy from a branch.
  4. Pilih branch main.
  5. Pilih folder /(root).
  6. Klik Save.

Tunggu sampai proses publikasi selesai.

07. Membuka dan Membagikan Website

Buka alamat website sesuai username GitHub:

Contoh alamat:
https://username.github.io/

Jika website sudah tampil, salin link tersebut dan bagikan kepada guru atau siswa melalui WhatsApp maupun media lainnya.

08. Mengatasi Kendala

Website menampilkan Error 404

Periksa nama repository dan pastikan file utama bernama index.html dengan huruf kecil.

Perubahan belum terlihat

Tunggu beberapa menit kemudian tekan Ctrl + F5 untuk memperbarui halaman.

Website tidak bisa dibuka

Periksa kembali pengaturan GitHub Pages, branch main, dan folder root.
