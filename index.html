Materi Pembelajaran

Materi 1: Mengenal dan Membuat Akun GitHub

GitHub adalah platform untuk menyimpan, mengelola, dan mengembangkan proyek digital. Guru dapat menggunakan GitHub untuk membuat website pembelajaran.

Langkah 1: Mendaftar GitHub dengan Gmail

  1. Buka GitHub Signup .
  2. Masukkan alamat Gmail Anda.
  3. Buat password yang kuat.
  4. Pilih username menggunakan huruf kecil, tanpa spasi, singkat, dan profesional.
  5. Selesaikan puzzle verifikasi.
  6. Masukkan kode verifikasi yang dikirim ke Gmail dan pilih paket Free jika diminta.

Tips untuk Guru

Pilih username dengan hati-hati karena username menjadi bagian dari alamat profil GitHub. Periksa folder Spam atau Promosi jika kode verifikasi tidak ditemukan. Simpan username dengan baik dan jangan membagikan password kepada orang lain.
