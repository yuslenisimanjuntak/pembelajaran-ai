Materi 1: Mengenal dan Membuat Akun GitHub

Selamat datang di materi pertama. Pada pembelajaran ini, Bapak/Ibu guru akan belajar mengenal GitHub dan membuat akun GitHub menggunakan Gmail.

A. Apa Itu GitHub?

GitHub adalah platform untuk menyimpan, mengelola, dan mengembangkan proyek digital. Guru dapat memanfaatkannya untuk membuat website pribadi dan media pembelajaran.

B. Langkah Mendaftar GitHub

Langkah 1: Membuka halaman pendaftaran

Buka alamat berikut: https://github.com/signup

Langkah 2: Memasukkan Gmail

Masukkan alamat Gmail yang masih aktif.

Langkah 3: Membuat password

Buat password yang kuat dan mudah Anda simpan dengan aman.

Langkah 4: Memilih username

Gunakan huruf kecil, tanpa spasi, singkat, dan profesional.

Langkah 5: Verifikasi

Selesaikan proses verifikasi yang diminta GitHub.

Langkah 6: Memasukkan kode

Masukkan kode verifikasi yang dikirimkan ke alamat Gmail Anda. Jika diminta memilih paket, pilih Free.

C. Tips untuk Guru

  • Gunakan Gmail yang aktif.
  • Pilih username yang profesional.
  • Simpan username dengan baik.
  • Jangan membagikan password kepada orang lain.

D. Tujuan Pembelajaran

Setelah mempelajari materi ini, guru diharapkan mampu:

  1. Menjelaskan pengertian GitHub.
  2. Memahami manfaat GitHub.
  3. Membuat akun GitHub secara mandiri.
